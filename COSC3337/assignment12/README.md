# 📘 Assignment 12 – NoSQL Databases (MongoDB)

This assignment demonstrates how to migrate relational-style tables into a NoSQL MongoDB database and execute analytical queries using Python and `pymongo`.

The project uses the following data files:

- **customer.tbl**
- **orders.tbl**

Both files follow a TPCH-style pipe-delimited layout.

---

## ✅ 1. Requirements

### **Software**
- Python **3.8+**
- MongoDB running on **localhost:27017**
